Mini DDR (short for Mini Dance Dance Revolution) is a project based on the arcade game “Dance Dance
Revolution”, but instead of dancing with your body, you dance with your fingers!

Project Overview
This project will use several resources from the Makerspace, including 3D printers, PCBs, solder,
Arduino, breadboards, wires, LEDs, resistors, or laser cutting materials. We are considering a
laptop to process the game and display it on a screen instead of the color display listed under
Project Hardware Needs.

Description of Proposed Gameplay
The game objects will include both a 9 pad dance board, and a screen to display preloaded Dance
Dance Revolution choreography. These components will be scaled down for the intended use of dancing
with your fingers (rather than your feet!). The user will be provided novel glove options to tie
back both the ring and pinky finger to their palm, as they will only be permitted to use their
middle and index finger to dance. The user will choose a song to dance to, and with their thumb
must maintain pressure on the back handlebar for the duration of the song. Releasing the bar will
result in the game terminating. The user will then dance away! The main menu will retain a
leaderboard for the event.
